## 确认的根因(基于你的报错)

- 你在 macOS **12.7.6**,app 的 `Info.plist` 声明 `LSMinimumSystemVersion = 13.0` → 被 macOS 启动门拦截(就是那个弹窗)。
- 上游 Sparkle appcast 里 `minimumSystemVersion` 仍是 **12.0** → 强烈说明上游 Electron 二进制在 12.x 上**实际可运行**,13.0 只是 plist 硬门槛(上游疏漏)。
- 本仓库 `buildMac()` 用 `ditto` 整包复制上游 `.app`,只改 `app.asar` 和 `ElectronAsarIntegrity`,**从不碰 `LSMinimumSystemVersion`**,所以原样继承了 13.0。

## 修复方案

### 第 1 步 · `scripts/build-from-upstream.js` —— 新增 helper + 调用

**(a)** 在 `updateAsarIntegrity()`(第 292 行)旁边新增,风格对齐现有 plutil 用法:

```js
function overrideMinimumSystemVersion(infoPlistPath) {
  const target = process.env.MACOS_MIN_VERSION || "12.0"; // 对齐上游 appcast 运行时底线
  try {
    execSync(`plutil -replace LSMinimumSystemVersion -string "${target}" "${infoPlistPath}"`, { stdio: "pipe" });
  } catch {
    execSync(`plutil -insert LSMinimumSystemVersion -string "${target}" "${infoPlistPath}"`, { stdio: "pipe" });
  }
  console.log(`   [min-os] LSMinimumSystemVersion -> ${target}`);
}
```

**(b)** 在 `buildMac()` 第 170-173 行的 plist 块里加一行,复用同一个 `infoPlist`:

```js
const infoPlist = path.join(outApp, "Contents", "Info.plist");
if (fs.existsSync(infoPlist)) {
  updateAsarIntegrity(asarPath, infoPlist);
  overrideMinimumSystemVersion(infoPlist);   // ← 新增,在 codesign 之前
}
```

要点:
- **默认就生效**(12.0),无需 CI 配置 → 打出的包直接支持你的 12.7.6。
- 保留 `MACOS_MIN_VERSION` 环境变量覆盖口,以后想调(比如上游哪天真要求 13)不用改代码。
- `replace`→`insert` 兜底,兼容 key 缺失的情况。

### 第 2 步(可选,先不做) · CI env / runner 钉版本

第 1 步默认值已经够用,先不动 workflow。如果将来想做"CI 可调最低版本"或把 `macos-latest` 钉到 `macos-14` 提可复现性,再单独加,不影响本次修复。

## 为什么默认 12.0 而不是 11.0

- 12.0 = 上游 Sparkle appcast 自己声明的运行时底线,是最有依据的"安全下限"。
- 你的机器是 12.7.6,12.0 正好覆盖。
- 再往下(11.0)超出上游声明范围,运行时崩溃风险升高,没必要冒。

## 验收

1. 跑一次 `npm run build:mac-x64`(本地 Mac 或 CI)
2. `plutil -p out/mac-x64/Codex.app/Contents/Info.plist | grep LSMinimumSystemVersion` → 应为 `12.0`
3. 在你的 macOS 12.7.6 机器上装这个 DMG,确认**能启动且正常使用**(不只是能打开)
4. 万一启动后闪退(极不可能,因为 appcast 自己说支持 12.0),再回退讨论

## 不改的东西

- `sync-upstream.js`、`patch-all.js`、`forge.config.js`、两个 workflow 全部不动
- 只在 `build-from-upstream.js` 新增一个函数 + 一行调用,改动面最小
